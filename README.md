Problema: Estudantes iniciantes de violão e guitarra frequentemente se sentem frustrados e desistem de aprender suas músicas favoritas devido à complexidade das cifras originais, que muitas vezes exigem acordes complexos (como pestanas) ou posições avançadas. Adaptar uma cifra manualmente requer conhecimento de teoria musical (como transposição de tom ou uso de capotraste), o que o iniciante ainda não possui.

Solução (O Agente): O projeto consiste em um agente virtual interativo que atua como um professor de música paciente. Ele recebe o nome de uma música, fornece a cifra e, por meio de interação em linguagem natural, adapta a dificuldade dos acordes de acordo com o feedback do usuário. O agente pode simplificar acordes, sugerir o uso de capotraste e explicar como posicionar os dedos, mantendo o contexto da música escolhida durante toda a conversa.
